# SD-ON RADIO

Нативное интернет-радио на Go для Steam Deck. Приложение запускается отдельно,
не встраивается в Steam, не изменяет файлы Steam и не требует `sudo`.

## Возможности

- тёмный русскоязычный интерфейс, адаптированный под экран 1280×800;
- воспроизведение, пауза, остановка и независимая громкость;
- автоматическое переподключение к потоку;
- встроенные и пользовательские станции;
- добавление, редактирование и удаление своих станций;
- сохранение громкости, последней станции и пользовательского списка;
- управление мышью, сенсорным экраном, клавиатурой и геймпадом;
- единый `.sh`-установщик с меню установки и удаления.

## Встроенные станции

- Hard Rock Heaven
- НАШЕ Радио
- Европа Плюс
- Relax FM
- ENERGY FM
- Радио Maximum
- ULTRA

## Архитектура

- Go 1.23;
- [Fyne](https://fyne.io/) — графический интерфейс;
- [Oto](https://github.com/ebitengine/oto) — вывод PCM-звука через ALSA;
- `ffmpeg` из SteamOS — декодирование MP3/AAC/AACP-потоков.

Установщик не включает FFmpeg: актуальная SteamOS уже содержит его. Никакие
системные пакеты во время установки не изменяются.

## Установка

```sh
chmod +x sd-on-radio-installer.sh
./sd-on-radio-installer.sh
```

При запуске без параметров установщик предлагает:

1. установить или обновить приложение;
2. удалить приложение и настройки;
3. выйти.

Для автоматизации:

```sh
./sd-on-radio-installer.sh --install
./sd-on-radio-installer.sh --uninstall
./sd-on-radio-installer.sh --help
```

Установка создаёт:

- `~/.local/share/sd-on-radio/app/`;
- `~/.local/bin/sd-on-radio`;
- `~/.local/share/applications/sd-on-radio.desktop`.

Удаление удаляет приложение, ярлык, настройки и пользовательские станции.

## Управление на Steam Deck

- крестовина / левый стик — выбрать станцию;
- **A** — воспроизвести выбранную станцию;
- **B** — остановить;
- **X** или **Y** — воспроизведение / пауза;
- **L1 / R1** — изменить громкость.

Элементы интерфейса также доступны для сенсорного управления. Добавление и
редактирование станций выполняется через экранную клавиатуру Steam.

## Хранение настроек

```text
~/.local/share/sd-on-radio/settings.json
```

Пример:

```json
{
  "stations": [
    {
      "name": "Моя станция",
      "url": "https://example.com/stream.mp3"
    }
  ],
  "last_station": "НАШЕ Радио",
  "volume": 0.8
}
```

Принимаются только URL с протоколом `http://` или `https://`. Файл записывается
атомарно с правами `0600`.

## Разработка

Требуются Go 1.23, компилятор C и заголовочные файлы X11, OpenGL и ALSA.

Для Ubuntu:

```sh
sudo apt install golang-1.23-go gcc libgl1-mesa-dev xorg-dev libasound2-dev
```

Проверки:

```sh
go test ./...
go vet ./...
go build ./...
```

Запуск из исходников:

```sh
go run ./cmd/sd-on-radio
```

Сборка единого установщика:

```sh
./scripts/build-installer.sh
```

Результат:

```text
dist/sd-on-radio-installer.sh
```
